# Architecture Decision Records Overview

Canonical index: [ADR.md](../ADR.md). The decision list lives only there; add
each new record's link to that index and mark superseded records.

## Record criteria

Create an ADR only for an implemented or explicitly accepted structural choice with meaningful alternatives. Include context, the chosen decision, rejected alternatives, consequences, and source/command evidence. Implementation notes and solved incidents belong in source comments or the cautions family instead.
