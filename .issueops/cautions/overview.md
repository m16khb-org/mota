# Cautions Overview

Canonical index: [CAUTIONS.md](../CAUTIONS.md). The record list lives only
there; add each new record's link to that index.

## Recording rule

Record only a reproduced failure or recurring false case after its resolution is known. Include the trigger, fix, and concrete source/test evidence. Put normative architecture, conventions, API contracts, and test practices in their single owning documents instead.
